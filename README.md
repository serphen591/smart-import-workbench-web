# 智能录题工作台 · 网页发布仓库

[打开在线工作台](https://serphen591.github.io/smart-import-workbench-web/)

此公开仓库仅包含编译后的网页和部署配置，不包含私有源码历史、题库样本、草稿或 API 密钥。源版本：`81d45630b149f60e6dfefa1fd97223891ff5cfc0`。

文档在浏览器中解析，草稿保存在当前浏览器 IndexedDB；清理网站数据会删除草稿，请定期导出完整备份。PDF 使用内置原始分页阅读器；DOCX 使用浏览器 Word 阅读器（排版可能与 Word/WPS 不同）。两种文档均可直接在当前阅读器圈选，无需补传 PDF；裁剪缩略图经人工核对所属题目后才能绑定或送给 AI。题目文字中的 LaTeX 自动渲染，仍保留源码编辑。扫描件不支持整卷 OCR。

DeepSeek 使用用户自行填写的新密钥，仅保存在当前标签页内存。确认圈选后才将该区域发送到 DeepSeek；API 按用量计费，需人工确认候选。不会自动上传原教学系统。

公共 GitHub Pages 承载静态站点，不运行 Python，也不启用付费云服务。
